How it works

The text is written into a grid, then rows and columns are shuffled by two secret keys.

1

Fill the grid

The message is written row by row into an R × C grid. Short messages are padded with underscores.

2

Permute rows, then columns

The row key reorders the rows and the column key reorders the columns. The result is read out row by row.

3

Break it by search

The attack tries every row and column permutation, scores each candidate by how many English words it contains, and ranks the results.

Why brute force has limits

The key space is R! × C!, which grows explosively with the grid size.

About the project

What it does

  • Encrypts and decrypts with user-defined row and column keys
  • Brute-forces all key pairs when the grid size is known
  • Tests every valid grid size when it is unknown
  • Ranks candidates with a dictionary-based English score (0–100)

Engineering notes

  • Pure Java backend (built-in HttpServer, no libraries)
  • Key validation with clear error messages
  • Multithreaded search on all CPU cores with live progress
  • Statistical scoring: real-word coverage plus English letter-pair analysis
